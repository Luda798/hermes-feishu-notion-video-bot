# Prompts 目录

这里放给用户复制到飞书 Hermes Bot 的提示词。

## 推荐使用顺序

1. 先用 [`bootstrap-prompt.md`](bootstrap-prompt.md) 里的 **版本 A：小白两句话版**。
2. 如果 Bot 执行不完整，再用 **版本 B：详细稳定版**。
3. 如果初始化中途失败，修复问题后用 **版本 C：继续处理 Prompt**。
4. 初始化完成并重启后，用 **版本 D：测试链接 Prompt** 测试抖音/小红书/微信公众号链接。
