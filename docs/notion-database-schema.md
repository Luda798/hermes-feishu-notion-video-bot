# Notion 数据库字段模板

建议用户新建一个空白 Notion 数据库，然后让 Bot 自动补齐字段；如果自动补齐失败，可以手动按下表创建。

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 标题 | Title | 是 | Notion 数据库默认标题字段，可重命名为 `标题` |
| 原始链接 | URL | 是 | 用户发来的原始链接 |
| 标准化链接 | URL | 否 | 解析跳转后的 canonical URL |
| 平台 | Select | 是 | 抖音 / 小红书 / 微信公众号 / 其他 |
| 内容类型 | Select | 是 | 视频 / 图文 / 文章 / 未知 / 测试 |
| 处理状态 | Select | 是 | 待处理 / 提取中 / 已整理 / 待复核 / 失败 |
| 作者或来源 | Rich text | 否 | 作者、账号、公众号名称等 |
| 摘要 | Rich text | 否 | 简短摘要 |
| 关键观点 | Rich text | 否 | 核心观点，建议用分号或换行分隔 |
| 可行动结论 | Rich text | 否 | 用户可以采取的行动建议 |
| 标签 | Multi-select | 否 | 内容标签 |
| 主题 | Multi-select | 否 | 主题分类 |
| 收集时间 | Date | 否 | Bot 接收到链接的时间 |
| 重试次数 | Number | 否 | 失败重试次数，默认 0 |
| 置信度 | Number | 否 | 0-1，表示整理可靠程度 |
| 处理日志 | Rich text | 否 | 简短记录处理过程和失败原因 |
| 平台内容ID | Rich text | 否 | 抖音 aweme_id、小红书 note_id、公众号文章 key 等 |
| 去重键 | Rich text | 否 | `平台:内容ID` 或标准化链接，用于去重 |
| 证据等级 | Select | 否 | high / medium / low / none |
| 证据来源 | Multi-select | 否 | ASR / 公众号正文 / 页面可见文本 / 平台章节 / 元数据 |
| 失败类型 | Select | 否 | 登录限制 / 风控反爬 / 链接失效 / 媒体不可下载 / ASR失败 / Notion写入失败 / 不支持平台 |
| 最后错误 | Rich text | 否 | 最近一次失败的简短原因 |
| 最后处理时间 | Date | 否 | 最近一次处理或重试时间 |


### 内容类型

## 页面正文模板

每个 Notion 页面正文建议使用：

```text
整理版
一句话结论
摘要
核心观点
可行动结论
关键原话 / 高亮
原文 / 转写文本 / 可用证据
元数据
来源链接
处理说明与可靠性
```

## 证据与状态规则

| 证据情况 | 建议状态 | 置信度 |
|---|---|---|
| 完整公众号正文 | 已整理 | 0.90-0.98 |
| 完整视频 ASR/字幕 | 已整理 | 0.85-0.95 |
| 图文正文可见 | 已整理 | 0.85-0.95 |
| 只有章节/描述/可见片段 | 待复核或已整理但注明限制 | 0.60-0.85 |
| 只有标题/作者/封面 | 待复核 | 0.30-0.60 |
| 链接不可访问 | 失败或待复核 | 0-0.30 |
